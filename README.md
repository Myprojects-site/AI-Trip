# 다음역

유럽 자유여행을 위한 개인용 플래너입니다. 서버 없이 동작하며 GitHub Pages에 그대로 올릴 수 있습니다.

## 바로 실행

`index.html`을 더블클릭하면 열립니다. 빌드나 설치가 필요 없습니다.

## GitHub Pages에 올리기

1. GitHub에서 새 저장소를 만듭니다.
2. 이 폴더의 파일을 모두 저장소 첫 위치에 올립니다.
3. 저장소의 Settings > Pages에서 Branch를 `main`, 폴더를 `/ (root)`로 고릅니다.
4. 잠시 뒤 표시되는 주소를 지인에게 보냅니다.

주의: GitHub Pages 주소는 아는 사람이면 누구나 열 수 있습니다. 사이트 코드만 공개되고, 여행 내용과 API 키는 각자 브라우저에 있습니다.

## 기능

- 노선: 도시 추가, 순서 변경, 박 수 조절, 구간 수단과 시간
- 일정표: 시간 단위 칸, 끌어서 옮기기, 규칙 기반 자동 초안, 겹침과 이동 시간 점검, 일몰 시각
- 동선: 점 지도 재생, 날짜별 간이 지도, Google 지도 대중교통 연결
- 예약: 항공, 숙소, 구간, 입장권의 권장 시점 체크리스트, 캘린더(.ics) 내보내기
- 교통: 철도 패스와 구간권 비교, 도시 교통권 비교
- 숙소: 동네 안내, 날짜가 채워진 검색 링크
- 비용: 추정과 확정 금액, 1인 합계
- 서류: 항공권과 바우처 보관(브라우저 저장)
- 안내서: 긴급 연락처와 일정을 묶은 인쇄용 PDF
- 공유: 링크 또는 JSON 파일로 사본 전달, 되돌리기
- AI: 대화로 여행 수정, 조건별 노선 제안, 예약 파일로 여행 만들기

## AI 설정

화면의 설정에서 각자 Anthropic API 키를 입력합니다. 키는 그 브라우저에만 저장되고 Anthropic API로만 전송됩니다.
비용은 키 주인 계정에 청구됩니다. 설정에서 모델과 월 토큰 한도를 정할 수 있고, 기본값은 Haiku 5.5와 20만 토큰입니다.

키를 코드나 저장소에 넣지 마세요. 공개된 키는 다른 사람이 쓸 수 있습니다.

## 데이터 수정

- 도시와 장소: `assets/data-cities.js`
- 구간, 예약 시기, 요금, 패스, 예시 노선: `assets/data-rules.js`

도시 설명, 추천 박 수, 계절 점수, 구간 시간과 요금은 직접 정리한 참고값입니다. 실제 여행 통계가 아니므로 예약 전에 공식 사이트에서 확인하세요.
철도 패스 가격은 2026년 11월 공식 페이지 표시가를 기준으로 넣었습니다.

## 넣지 않은 기능

- 실시간 대중교통 경로: Google 지도로 연결합니다.
- 3D 지도: 2D 동선 재생으로 대신합니다.
- 예약 메일 주소: 메일 수신 서버가 필요해 제외했습니다.
- 여러 사람의 동시 편집: 서버가 필요해 제외했습니다. 공유하면 사본이 만들어집니다.
